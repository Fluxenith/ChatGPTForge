# 桌面／工作列與跨視窗拖放

`desktop_surface` 提供全桌面觀察、實體左鍵點擊與兩個視窗之間的拖放。需本機 Manager 核准完整桌面工作階段，以及有效任務 lease；僅允許截圖的授權不足以使用此工具。

1. 呼叫 `action: "observe"`，取得全桌面影像、`revision`、虛擬螢幕範圍與 `targets`。目標包含可操作視窗，以及已核對 Explorer 程序身分的桌面／工作列。
2. 點擊使用 `action: "click"`、最新 `revision`、`source_hwnd` 與影像內的 `x,y`。依實際影像確認目標；不能只根據視窗矩形猜測按鈕。
3. 拖放使用 `action: "drag"`，另傳 `destination_hwnd`、`end_x,end_y`。來源與目的地必須是不同、可操作且端點未被遮住的視窗。這是實體滑鼠拖放，應用必須支援相應的拖放格式。
4. 結果的 `post_observation` 是動作後的新影像及 revision。`post_state_observed` 只代表觀察成功；還須核對目的應用的實際內容，才能判定操作成功。

座標以回傳影像左上角為原點，不能直接使用實體螢幕座標。換算包含虛擬螢幕的負原點、縮放及多螢幕範圍；輸入前會再次核對螢幕配置、視窗程序／建立時間、矩形與原生命中位置。觀察有效期為 120 秒，任何真人輸入都需要重新觀察。

拖曳路徑不能經過第三個應用；來源、目的地與真正的桌面 shell 以外的路徑會拒絕。工具不會自動挪動視窗或強制切換前景。密碼欄位與既有排除應用仍受限制，不得藉工作列捷徑操作排除的應用。這個版本不提供任意全桌面鍵盤輸入或自動檔案搬移。

每次動作使用唯一 `operation_id`。相同操作重送只回傳回執，不再送出滑鼠輸入；unknown 操作不可直接重試，需核對實際狀態再依既有流程處理。真人鍵鼠活動、Escape、授權撤回或視窗變動會中止；拖曳中止時原生處理會釋放左鍵。
